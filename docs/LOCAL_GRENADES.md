# 本地 CS2 投掷物系统

入口：`http://localhost:5173/` → **投掷物训练**。正常比赛使用同一套投掷、碰撞、伤害和烟火交互，训练额外提供无限装备、轨迹与落点。

## 当前实现

- 六类原始模型：HE、Flashbang、Smoke、Molotov、Incendiary、Decoy；54 段第一人称动作、六个原始 HUD 图标。包含掏出、拔销、三档持握、上手 / 下手投掷和检视。机器人也接入原始拔销与投掷动作，出手前显示手中道具。
- 左键长抛、右键短抛、双键中抛；松手后按动作延迟释放。持雷不会预先消耗引信，切换或暂停可以取消未出手的准备动作。继承移动 / 起跳速度，使用带半径的扫掠碰撞，处理反弹、摩擦、落地与静止，适配原图的 grenadeclip。
- HE 按爆点到人体多个采样点判断遮挡，计算距离衰减与护甲；爆炸使用原始火球 / 烟尘图集、碎屑及短暂光照。
- 闪光根据距离、朝向和眼位遮挡控制白屏、衰减、耳鸣与听觉低通；GPU 直接保存残像，不做画布截图或 CPU 像素回读。
- 烟雾采用受墙体限制的三维密度格，填充相连空间；子弹穿孔和 HE 清空区域会恢复。机器人视线与画面共享密度格和孔洞状态。烟幕内的诱饵声源也产生小范围扰动。
- 烟雾弹触火提前展开，实际接触到的燃烧单元被扑灭，不按跨墙中心距离一律熄灭。燃烧瓶 / 燃烧弹的展开速度、范围和持续时间不同；火焰贴地扩散，并随时间降低高度。
- 诱饵使用投掷者的主武器 / 手枪原始枪声，吸引附近敌方机器人的声音记忆，不发射真实子弹。烟罐与诱饵实体保留到效果结束。
- 竞技携带总量 4 枚、闪光最多 2 枚、燃烧装备互斥；区分携带量与回合购买配额，防止丢下后无限补购。支持 G 丢弃、E 拾取与阵亡掉落。训练可自由选择六类装备。
- 原始投掷、拔销、碰撞、引爆、玻璃碎裂、燃烧循环和灭火音效；补充双方燃烧 / 诱饵无线电。环境声音随暂停停止，并随场景清理释放。

## 操作

| 操作 | 按键 |
| --- | --- |
| 循环选择携带的投掷物 | 4 |
| HE / 闪光 / 烟雾 / 诱饵 / 燃烧装备 | 6 / 7 / 8 / 9 / 0 |
| 长抛 / 短抛 / 中抛 | 按住左键 / 右键 / 双键，松手投出 |
| 跳投 / 跑投 | 持雷时使用空格 / WASD，并在合适时机松手 |
| 检视 | F |
| 丢弃 / 拾取 | G / E |
| 训练中选择装备 | B |

轨迹只在训练里显示，和实际飞行共用同一碰撞求解；每秒最多更新约八次，包含弹跳标记、距离和引爆时间。

## 性能设计

保留此前的 60 / 90 / 120 FPS 上限、暂停按需绘制、后台停绘、角色距离分级与静态阴影缓存。

- 每团烟使用 `24 × 16 × 24` R8 密度，单张 GPU 密度纹理 9 KiB；全局固定烘焙预算每模拟步最多 384 次查询，多团烟公平分摊。
- 画面只渲染视锥内的烟。体积层按高 / 中 / 低画质使用 50% / 40% / 32% 线性分辨率和 40 / 32 / 24 步；透射率饱和提前退出。
- 烟雾复用一次世界渲染的深度纹理，不为烟雾重新绘制整张地图；全分辨率第一人称模型和 HTML HUD 保持原样。烟、火不投实时阴影，实体投掷物仍走动态阴影。
- 最多 10 团烟、10 片火、32 枚飞行弹体；火焰使用单图集实例化，固定 840 个单元上限。爆炸、弹道、粒子和投掷物模型复用，爆炸灯也复用。
- 燃烧伤害按 0.2 秒步进，避免每帧创建受伤声音与提示。纹理保留原图内容并限制在 2K；燃烧瓶专用液体材质使用轻量 PBR 适配，不触发全场景透射重绘。

### 历史对照采样（2026-09-25）

Chrome，高画质、60 FPS 上限，压测画布 2380 × 1327，世界缩放 100%。同一 A 大机位放置九个原始角色，取各自最近 1800 个绘制帧；压测固定保留六团烟和两片火（162 个单元），用于稳定比较渲染负载。

| 指标 | 无特效基准 | 六烟 + 两火 |
| --- | ---: | ---: |
| 帧间隔中位数 | 16.7 ms | 16.7 ms |
| 帧间隔 p95 | 24.4 ms | 24.1 ms |
| 帧中 JavaScript 工作时间中位数 | 5.4 ms | 5.2 ms |
| JavaScript 工作时间 p95 | 5.7 ms | 5.6 ms |
| 绘制调用 | 569 | 577 |
| 三角形（含阴影） | 1,984,172 | 1,984,570 |

统计上的小幅下降属于测量波动，不声称特效能让游戏变快。上述是固定场景的帧间隔和 JavaScript 时间，**不是 GPU 计时、温度或功耗测量**；也不是每一帧均达到 60 FPS 的保证。压测烟层实际为 1190 × 664，六张密度纹理共 55,296 字节，静态阴影仍只烘焙一次。

## 原始资源与可重建性

与现有地图一致：Steam app 730 / depot 2347770 / manifest `5009084625236407721`。当前武器表给出的价格为 HE300、Flash200、Smoke300、Molotov400、Incendiary500、Decoy50；六类 `ThrowVelocity=750` Source units/s、持有移动速度 `245`。原始参数、路径和声音事件保存在本机运行清单，出处与官方行为见 [GRENADE_RESEARCH.md](GRENADE_RESEARCH.md)。

```sh
pnpm exec tsx scripts/prepare-source2-grenade-data.ts
python3 scripts/export-source2-grenades.py
pnpm exec tsx scripts/prepare-source2-grenades.ts
python3 scripts/export-source2-grenade-media.py
pnpm exec tsx scripts/prepare-source2-grenade-vfx.ts
pnpm exec tsx scripts/prepare-source2-explosion-vfx.ts
```

转换需要本机已有 VPK、VRF / .NET 工具和解码后的原始 AO 参考图；输入清单在 `scripts/source2-grenades.json`。角色额外动作沿用 `export-source2-characters.py` / `prepare-source2-characters.ts`，无线电沿用 `prepare-source2-media.ts` / `export-source2-media.py`。素材保持本地并排除于 Git，没有部署。

## 还原边界

模型、贴图、动作、图标与声音直接使用原始资源。飞行积分、触发时间、伤害曲线、烟雾密度 / 孔洞、火焰扩散与玻璃 / 液体着色为浏览器重建；当前公开资料及武器表不包含 Source 2 的全部实现常量。体积烟并非 Valve 原生流体求解器，火焰 / 爆炸图集的组合也不是完整移植 VPCF 算子。不能宣称逐像素、逐帧或所有投掷点位与官方引擎一致。
