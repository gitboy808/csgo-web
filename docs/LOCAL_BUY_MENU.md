# 本地 CS2 购买菜单

正常对局按 **B** 打开。界面参照当前固定版本的 `panorama/layout/buymenu.vxml_c`、`panorama/styles/buymenu.vcss_c` 和中文资源，采用装备、手枪、中型武器、步枪、投掷物五列，列宽比例为 **18 / 18 / 22 / 24 / 18**。

## 画面与交互

- 使用原始武器、投掷物、防具、拆弹器、C4 和退款图标。资金、购买时间、下回合最低金额、已持有状态、队友装备圆点和地面装备与实际对局数据联动。
- SAS / Phoenix 预览共享场内模型和纹理，使用原版购买菜单专用的 **26 组静态姿势**。悬停或键盘选中武器、投掷物会更新预览。
- 数字键 **1–5** 先选择分类，再选择该列栏位。**F3** 自动购买，**F4** 再次购买先前装备；重购计划保留到下一回合，包括阵亡或已消耗的装备。
- 点击退款箭头或「全部退款」退还本回合符合条件的装备。携带而来的枪械、已使用或已经丢弃的枪械不会产生退款；退款撤销相应投掷物购买配额。已有完整防弹衣时，补购头盔价格为 **$350**。
- **Ctrl + 点击**购买并投掷枪械或投掷物；支持 macOS 的 Control-click 右键事件，避免重复购买。点击地面列表可拾取购买区内可见的己方装备；T 方也可拾取掉落的 C4。
- **B / Esc** 返回对局。键盘焦点保持在购买对话框内。

购买时间与下回合金额来自本项目比赛规则。官方地面装备和最低余额功能参照 [Valve 的购买菜单更新](https://store.steampowered.com/news/posts/?appids=730&enddate=1714172977&feed=steam_community_announcements)。

## 性能

- 购买只更新价格、状态和数量，不重建整个菜单。鼠标预览有 90 ms 合并延迟，旧请求不会覆盖新选择。
- 使用现有 WebGL renderer、一个 640 × 864 渲染目标和独立显示骨架，不复制整套角色战斗动画。着色器异步预编译，等待期间恢复主场景渲染状态。
- 直接缓存画布像素，避免同步图片编码；最多缓存 **8 张**预览，RGBA 数据约 **17 MiB**，命中缓存时无需再次绘制 3D 场景。
- 菜单停留不运行角色动画循环。窄于或等于 760 px 的窗口隐藏预览，并停止请求额外头像绘制。
- 新增运行资源 **585,264 字节，约 0.56 MiB**，包含七个 SVG、姿势数据和来源清单；模型、纹理和已有枪械/投掷物图标均复用。

历史浏览器实测（2026-09-25）：1280 × 720 菜单静止 2 秒，世界和头像新增绘制均为 **0**；720 × 720 窗口中预览隐藏，切换装备也没有新增头像绘制。首次显示未上传的高分辨率武器可能仍有约 0.2 秒的准备成本；缓存命中不重复这一步。这些记录不等同于 GPU 计时或功耗测量。

## 素材重建

使用与地图相同的 Steam app 730 / depot 2347770 / manifest `5009084625236407721`。购买姿势位于 `animation/anims/ui_anims/buy_menu/`，对应分卷 `game/csgo/pak01_498.vpk`。原始布局、中文参考和转换中间文件放在 `local-assets/buy-menu`；运行资源放在 `public/assets/source2/buy-menu`。

已有本机原始 VPK 和工具时：

```sh
.local-tools/dotnet/dotnet build scripts/source2-helper
python3 scripts/prepare-source2-buy-menu.py
python3 scripts/export-source2-buy-poses.py
pnpm exec tsx scripts/prepare-source2-buy-poses.ts
pnpm test
pnpm build
```

姿势导出不重复输出材质和纹理，只保存重定向后的骨骼姿态。原始素材保持本地，并由现有 Git 忽略规则排除。

## 适用范围

沿用现有七种武器和本地装备槽规则，未实现武器显示为空槽。角色采用原始购买姿势的静态预览，字体和光照由网页适配；本地打开购买界面时暂停对局。这里没有移植完整的 Panorama 界面引擎、官方完整武器池或持续待机动画。
