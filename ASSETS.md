# Asset provenance

## Environment materials — CC0 1.0

The following original Poly Haven assets are redistributed as 1K JPEG color, OpenGL normal and ambient/roughness/metalness maps. Source URLs and MD5 checksums are recorded in `public/assets/materials.json`.

| Local material | Original asset |
| --- | --- |
| Plaster | [Painted Plaster Wall](https://polyhaven.com/a/painted_plaster_wall) |
| Sandstone | [Sandstone Blocks 05](https://polyhaven.com/a/sandstone_blocks_05) |
| Road | [Asphalt 02](https://polyhaven.com/a/asphalt_02) |
| Paving | [Concrete Floor 02](https://polyhaven.com/a/concrete_floor_02) |
| Sand | [Aerial Sand](https://polyhaven.com/a/aerial_sand) |
| Wood | [Weathered Brown Planks](https://polyhaven.com/a/weathered_brown_planks) |
| Metal | [Rusty Painted Metal](https://polyhaven.com/a/rusty_painted_metal) |

License: <https://polyhaven.com/license>. Powered by Poly Haven. Assets were fetched using their documented API for this project. No asset API is queried at runtime.

## Fonts — SIL Open Font License

Barlow and Barlow Condensed, by Jeremy Tribby and contributors, bundled via `@fontsource/barlow` and `@fontsource/barlow-condensed`. Their license files are included with the installed packages. Font license: <https://openfontlicense.org/>.

## Original code-generated content

Architecture, map geometry, character and weapon meshes, props, signage, radar, decals, interface artwork and visual effects are generated by the source code in this project. Sounds are synthesized with Web Audio. No Valve model, texture, audio file, map file or logo is included.

Visual reference: [Valve's CS2 introduction](https://www.counter-strike.net/cs2) and [The Return of Dust II](https://www.counter-strike.net/dust2). This is an independent fan tribute, not an official Counter-Strike product.
